# Pekarna TOTAJ — celotna stran, pregledno ločena koda

Odpri **index.html** v brskalniku ali v VS Code z Live Server.

- `index.html`: vsi razdelki (Domov, Ponudba, O nas, Kontakt) na eni strani.
- `style.css`: vse oblikovanje.
- `script.js`: izdelki, fotografije izdelkov in mobilni meni.
- `assets/logo.png`: originalni logotip.

Navigacija vodi na razdelke na isti strani. Obvezno ohrani datoteke in mapo `assets` skupaj. Začasne fotografije se nalagajo s spleta, zato za njihov prikaz potrebuješ internetno povezavo.


Šumniki: datoteke so shranjene v UTF-8. V Visual Studio Code spodaj desno izberite UTF-8, če je potrebno.
